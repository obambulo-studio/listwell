# Social profiles posted recently

Inactive profiles look abandoned. We score how recently each readable profile published a public post.

::tech-detail{summary="How we score posting freshness"} We read the newest public post date on each profile we can open. Score is 100 within 7 days, 80 within 30 days, 50 within 90 days, and 0 after that. The check passes only when every readable profile scores at least 50. We do not invent a post date. ::

## What we're checking

Every readable social profile has a public post from the last 90 days. The row label shows each network, how long ago it posted, and the freshness score.

::impact{type="customers" severity="high"} Profiles that have not posted in months get fewer visits than active competitors ::

## How can I fix it?

Publish a new post on each profile that is older than 90 days.

::time-estimate{minutes="60" difficulty="easy"}::

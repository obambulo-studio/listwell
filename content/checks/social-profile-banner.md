# Social profiles have a banner

A cover image makes a profile look established. We check that each public social profile we can read has a banner or cover photo.

::tech-detail{summary="How we look for a banner"} We fetch each linked Facebook, Instagram, LinkedIn, TikTok, YouTube, and X profile and look for a cover image. An Open Graph image is not treated as a banner, because it is often the latest post. If the page is a login wall or cannot be read, the check does not run. We do not invent a missing image. ::

## What we're checking

Every readable profile should show a banner. Profiles we cannot read are skipped.

::impact{type="customers" severity="medium"} Profiles without a cover image look unfinished next to competitors who have one ::

## How can I fix it?

Upload a cover or banner image on each social profile, using the same artwork where the platform allows it.

::time-estimate{minutes="30" difficulty="easy"}::
